# Feature reduction follow-up

Apply after my-light-effects-reduction.patch, not to the upstream tree directly.

Removes Media Browser and VR Comp Editor UI, all 12 ec.vr effects from the available effect catalog,
VR composition commands, and the Tracker panel (motion/mask tracking, motion stabilization, Warp Stabilizer).
Removed commands cannot run through the engine. Saved layouts drop these three panels while preserving
other tabs. Browser thumbnails are no longer generated by the removed panel. Web directory restoration
is disabled. Warp Stabilizer analysis controls, automatic invalidation/reanalysis and new analysis entry
points are disabled. Existing project effect data and CPU/GPU render implementations remain for
compatibility. Some legacy tracker UI helper and analysis modules remain compiled; this is functional
removal, not a complete dependency or binary-size purge. No performance gain has been measured.

File import, Project panel, Metadata, 3D cameras, keyframe animation and H.264/MP4 export are retained.
No resolution, export or cache settings are changed.

Validation: patch application/reversal and static source checks; Rust compilation and Rust tests must
run on the user's machine because the patch authoring environment has no cargo installed.
Added regression coverage for command policy and saved-layout migration.

Build: cargo run --locked -p effectcraft -j 2
Targeted tests: cargo test --locked -p effectcraft-engine feature_policy
Targeted tests: cargo test --locked -p effectcraft-ui-egui fork_reduction_tests
Before committing, upstream instructions require cargo xtask ci.

Manual checks: open an existing saved workspace; verify Media Browser, Tracker and VR Comp Editor
are absent. Import footage, open a composition, play it, save/reopen, and export H.264/MP4.
For legacy projects, compare rendered output before overwriting the original project.

Rollback: git apply -R --check PATH_TO_PATCH && git apply -R PATH_TO_PATCH
